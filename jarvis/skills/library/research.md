An answer without a source is a guess with better grammar.

1. **Decide whether this genuinely needs the web.** Stable facts you already
   know reliably do not; anything current, versioned, priced, or specific to a
   named entity does.
2. **Search with keywords, not the user's sentence.** Search indexes match
   terms; "what does HTTP status 429 mean" retrieves worse than "HTTP 429".
3. **Read more than one source** when the answer is contested, recent, or
   commercially motivated. A single result is a lead, not a finding.
4. **Actually open the page** when the snippet is ambiguous. Snippets are
   truncated and frequently misleading.
5. **Report the answer, then the source.** Where sources disagree, say so
   rather than silently picking one.
6. **Separate what you found from what you inferred.** If you are extrapolating
   beyond what the source says, mark it as your inference.

If retrieval fails or returns nothing usable, say that plainly. Do not fall
back to reciting a plausible answer from memory and present it as researched.
